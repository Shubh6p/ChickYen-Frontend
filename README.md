# ChickYen Achar - Frontend 🍗🌶️

React.js (Vite + Tailwind CSS) application for the ChickYen Achar storefront and Admin Panel.

## Features
- **Storefront**: Responsive UI, product browsing, and slide-out cart checkout.
- **Admin Dashboard**: Complete management of orders, products, customers, and newsletters.
- **Auth**: Seamless passwordless OTP flow integrated with the backend API.

## Quick Setup
1. Clone the repo and run `npm install`.
2. Create a `.env` file and set `VITE_API_URL` to your backend URL (e.g. `http://localhost:5000/api`).
3. Run `npm run dev` to start the app.
